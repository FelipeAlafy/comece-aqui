# Requisitos para o desenvolvimento Android.

## Hardware:
O desenvolvimento para dispositivos móveis em geral não é conhecido exatamente por ser leve. Muito pelo contrário, pense no iOS por exemplo, ele demanda que o usuário possua obrigatoriamente algum acesso ao MacOS da Apple, que também se manifesta de mesma forma para o hardware, que em 99% das vezes deve ser um Mac.

Ainda que o Android, seja mil vezes mais acessível, ele não se torna tão acessível a qualquer um. Uma vez que 99% dos computadores consegue rodar um Navegador de Internet, isto torna possível em suma a 99% dos usuários destes computadores programarem para Web. Visto que, o básico necessário todos já tem, um Navegador e um Editor de texto, por mais desprovido de fuções que este possa ser. Para o Android, o ambiente padrão, pelo menos para nativo, é o Android Studio. Uma IDE, erguida dos braços do Intellij IDEA, que por sua vez, exigirá um hardware mminimo muito maior que a maioria das demais linguagens. Veja:

* O Android Studio costuma consumir muita memória de SSD, uma vez que, cada instalação de uma versão do Android consome mais de 1 Gb, fora os dados da IDE. Portanto, minha recomendação é que você tenha no mínimo um SSD de 256Gb.

* O Android Studio por si só recomenda que você tenha um processador que tenha suporte para virtualização, independentemente de marca, também é preciso que este tenha arquitetura 64 bits.

* A depender do seu hardware, para rodar o Emulador do Android diretamente no seu computador, o minimo necessário de memória ram será de 16 Gb.

* Caso você tenha acesso a um dispositivo Android e um cabo USB, é possível pular essa etapa de virtualização, e rodar o App diretamente no seu dispositivo via Depuração USB. Neste caso o minimo exigido é de 8Gb.

> [!NOTE]
> Note que também, com esse método, funções como preview não funcionaram corretamente, pois depende da emulação.

## Conhecimento necessário para seguir este RoadMap.
* É obrigatório que você já tenha consolidado em sua mente, conteúdos com Lógica de Programação.
* Conhecimento de estruturas como Vetores e Matrizes.
* Ainda que não seja obrigatório, um pouco de conhecimento em Java, pode facilitar a leitura de projetos mistos entre Kotlin e Java.
* Conhecimento em Git é obrigatório.

## Downloads e Configurações.
* Realize o Download do Git e instalação no seu sistema de prefêrencia.
* Realize o Downlaod do [Jetbrains Toolbox]().
* Instale o Jetbrains Toolbox, no geral basta executar o programa e ele se instala automaticamente.
* No caso do MacOS, arraste o app para sua pasta de Apps.
* No caso do Linux, o app é distribuido no formato de Apps Universais, basta extrair a pasta, salva-la em um local seguro, e executar o App. Na maioria dos casos o próprio JetBrains Toolbox, criará um atalho no seu menu para que seja possível acessar diretamente. Caso não crie, você pode usar um app como [Menu Principal](https://flathub.org/apps/page.codeberg.libre_menu_editor.LibreMenuEditor), para criar esse atalho.
* Faça a configuração do Toolbox, recomendo que você crie uma conta na jetbrains. Mas, não é obrigatório.
* Basta procurar pelo Android Studio na lista e clicar em Instalar.
* Após a instalação inicie o Android Studio e siga a configurações padrões do Android Studio para baixar todos os componentes essênciais como o SDK do Android, JVM, Gradle, Kotlin, Etc.
* Após isto você verá a tela inicial do Android Studio!
* Retorne ao Jetbrains Toolbox, e baixe também o Intellij IDEA, pode ser a versão Community Edition, ou a versão Ultimate.

> [!IMPORTANT]
> Note que para utilizar a versão ultimate do Intellij IDEA, é necessário que você possua uma licença paga, ou então tenha feito o processo do arquivo guia-de-ides.md, para realizar a ativação do seu benefício de estudante universitário.
* Após isto, você pode abrir o Intellij IDEA, e seguir a configuração padrão.
